Another reason [I hate dealing with MS](https://www.rockpenguin.com/2014/06/why-i-use-linux-and-not-microsoft/ "(One of the many reasons) Why I use Linux and not Microsoft"). I have had this issue with every version of Windows as far back as I can remember so obviously they will never fix the code.  So, you want to reconfigure a non-working printer or remove an old entry in the printer server "Ports" tab.  But Windows won't let you - it says that the "Resource is in use."  Huh?  I deleted the printer, now I just want to delete the local/TCP port.  Turns out there might have been old jobs sticking around and they need to be cleared out first.  Uggh.
