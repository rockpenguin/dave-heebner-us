For me, Linux on the laptop started with Slackware back in 1999.  It was relatively easy to install and really allowed me to learn Linux as it forced me to get down and dirty with CLI, while still allowing me to get some work done.  This helped me get more familiar with the finer points of managing a Linux system and helped me also start using Linux as a server and working via the CLI.  But after awhile all of that heavy lifting became a chore when I needed to "just have a working desktop".  I don't mind spending the time to tweak and setup Linux servers, but having to hand edit xorg.conf and compile kernels so that I could get the correct resolution on my monitor and get a working NIC card was getting old.  Then along came Ubuntu on the scene in 2004.  What a Godsend!  The ease of taking care of a Debian-based system but with more up-to-date packages, an easy to install distro based on the elegant yet simple Gnome DE that picked up most of the hardware right out of the box, and played nice with the media we are all accustomed to (MP3s, Flash).  And over the years it only got better with each release.  I finally felt I had reached desktop nirvana, where I could actually use my laptop to do my job - administer systems and run an IT department in a Windows-based world, and still enjoy the fun stuff like Youtube.  Like someone once said, "I work with Windows to get paid, but use Linux to get work done."  It was so easy to use and so compatible with today's media that I started installing it on family and friends computers that were repeatedly getting hit with malware.

But then it all started go terribly wrong.  Somewhere around v11.04 (I think), things started to go south.  In an effort to simplify things, Gnome decided to redefine the DE experience with v3.0 and Ubuntu started on their own version of Gnome called "Unity". Neither of these were production ready and were so stripped down that it took too much time to figure out how to get the useful stuff back in.  Where the hell was my taskbar???  But luckily there were plenty of people in the Ubuntu forums going through the same headaches and it was usually just a matter of "apt-get install this-or-that" to get back most of the functionality I was so used to with previous versions of Ubuntu.  But it didn't get any better with subsequent releases.  By the [12.10](http://en.wikipedia.org/wiki/Ubuntu_12.10_Quantal_Quetzal#Ubuntu_12.10_.28Quantal_Quetzal.29) release I was fed up.  So I started the search for the next DE that fit my needs - fully customizable, stable, and supportive of the software that Windows and Mac users enjoy such as Flash, MP3s, etc.

So I figured I'd stick with the "Ubuntu" base, but move on over to [Kubuntu](http://www.kubuntu.org/) or [Xubuntu](http://xubuntu.org/).

- Kubuntu - KDE and I have a love/hate relationship.  There are aspects of it that I love, especially with the 4.x series.  Some of the features are just awesome, like the glowing border around windows, and the desktop activities and applets.  But it still has the aspects that I hate, which are the "too much customization" and the ugliness of most of the K--- programs.  Many of them remind me of Win 3.x or Win 9x and I feel like I'm using a DE that was designed by high school kid who just made his/her first GUI program.  Every time I try KDE, I try to stick with it, but usually by the 3rd day I'm done.  I can't take it anymore and it's back to GTK I go.
- Xubuntu - I like XFCE and I use it on older hardware.  The interface is a little clunky and chunky, but it's getting better and better, especially since it supports compositing (yay transparent terminals).  However, it's still no Gnome and I always feel like I'm missing something.

Then Mint came along.  Oooh, this seems interesting.  A distro based on Ubuntu but with a bend towards the original Gnome 2.x look and feel.  This could be what I've been looking for.  So I used it for several months and overall really liked it, except it was still a little too rough around the edges and had too many bugs.  Could just be my hardware (Sony VAIO), I dunno.  But there were too many oddities, some really annoying like Firefox always asking me if I wanted to save my tabs, even though I check the box that says "[don't ask me again damnitall](https://www.google.com/search?q=mint+firefox+save+tabls#q=mint+firefox+save+tabs&spell=1)".  This is sometimes able to be [fixed](http://linuxnorth.wordpress.com/2013/07/15/fixing-firefoxs-multiple-tabs/), but it STILL happens no matter which spin of Mint you install.  There are other frustrating bugs like that, so I started my quest once again for a DE that "just works".

Long story short, I came back around to Fedora.  I had used Fedora in the past but it just never sat right with me.  SELinux is a PITA (yes, I know you can set it to permissive) and I just love Debian's package management system.  RPM always seemed like an "almost ran" compared to the apt package system.  But the more I started to use YUM, the more I liked it.  It was similar to apt-get (and aptitude) but maybe even easier.  So I downloaded F18 ("Spherical Cow") and gave it a try.  Wow!  What a difference since the "Fedora Core" versions.  And the new Gnome was really shaping up into a keyboard friendly desktop.  I could use the "Windows" key to search for and launch apps, much of the window "look and feel" customization was starting to come back and for the most part the DE stayed out of my way and let me get work done.  And there were very few annoying bugs, other than some issues with SELinux and things like VPN and other network settings.  But now it wasn't very difficult to get multimedia such as Flash and MP3 support installed, VirtualBox was easy to install (along with a "yum install dkms").
